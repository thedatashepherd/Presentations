## The talk

Already know SQL? Python notebooks in Microsoft Fabric let you bring those skills directly — no Spark, no relearning. DuckDB comes pre-installed, so you query Lakehouse data with familiar SQL syntax from day one. Learn when Python notebooks outperform Spark, follow a decision tree to pick the right tool, and leave with ready-to-run notebooks.
