## The talk

Microsoft Fabric can feel like a sprawling theme park on day one. This 100-level session is a park map: start on Main Street, find OneLake at the centre, walk through the lands, pick your first ride, and leave with a take-home map for what to try next.

## Demo resources

The demos followed one ride's wait time from a public API to a Power BI report: a notebook collects it, a Lakehouse stores it, Warehouse views shape it, and a semantic model and report show it. Everything you need to rebuild that route in your own workspace is in [Demos](Demos/README.md), along with a ready-made park data snapshot for the "Your first report" exercise.
