## Demos

Four tools, in the order they're demoed: capture in Obsidian, visualize in Excalidraw, execute in VS Code, and speed up daily work with PowerToys.

### `Demos/1. Obsidian/` — Capture
A full Obsidian vault (Fallout-universe themed) demonstrating core features: Graph View, Templates, Canvas, the Dataview plugin dashboard, Git/Excalidraw plugins, and Daily Notes. Open the folder itself as your Obsidian vault to follow along.

### `Demos/2. Excalidraw/` — Visualize
Diagram files (`.excalidraw`) used for the blank-canvas and pre-built-diagram walkthrough, including the Fallout Faction Map and the AWS / Microsoft Fabric architecture sketches. Open with the Excalidraw app or the Excalidraw VS Code extension.

### `Demos/3. VS Code/` — Execute
The VS Code project used for the CSV workflow (Rainbow CSV / CSV Lint), the Excalidraw-in-VS Code extension demo, and SQL Server / Fabric connection demos. See `START_HERE.md` inside that folder for setup. Uses [uv](https://docs.astral.sh/uv/) — run `uv sync` in that folder to recreate the environment (`uv.lock` included).

### PowerToys — Optimize
No files to hand out — this segment demos live OS utilities (ZoomIt, Command Palette, Advanced Paste, Color Picker, FancyZones). Get them at https://learn.microsoft.com/windows/powertoys/
